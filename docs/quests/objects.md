# Objects: which models a quest may place

**For whoever writes a Delve** (any `model` in a recipe, see [delve-recipes.md](delve-recipes.md)). Pick
from the approved table; a model that is not on it goes to him first. The twin of [voices.md](voices.md),
and the same rule: **a model nobody has seen in game is marked so, because a mesh path is not a look.**

*Started 2026-10-09 on his ruling: "we'll make a list of objects that are approved for quest usage and you
can check/rework as needs be." Seeded by Jessica from the models the recipes already use. Kim's kitbashes
join here when he approves them; the wish list for those is home-office
`office/projects/delves/quest-objects.md` (a request, not this list).*

## The rules an object is held to

- **It sits on the ground.** The lint grades it (delve-recipes.md, "a model must sit on the ground").
- **It looks right standing alone in a POI.** His, 2026-10-08: *"The display cabinet looks weird in the
  middle of a POI. Prob be a chest."* City and shop furniture reads wrong in the open.
- **No names.** Delves repeat across planets; a stencil is fine, a person is not.

## Adding an object

A row needs: the mesh path, **his** words for how it reads (or the playtest that showed it), whether it has
been seen in game, and which recipes use it. When an object is retired or replaced, the recipes that use it
get reworked in the same change (Jessica's lane for the words, the recipe for the path).
