# SpaceCellGen

Everything needed to generate procedural space cells (asteroid fields, debris zones, space encounters).

- **SpaceCellGenerator.cs** — Top-level generator: wires passes together and drives space cell creation
- **Designs/** — Space cell design definitions (rocky asteroids, ice crystals, wisps, etc.) + design registry
- **Passes/** — Individual generation passes (asteroid chains, comet tails, crescent belts, ice crystals, ship wrecks, space markers)
