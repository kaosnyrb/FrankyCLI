# Spec: NPC Conversational Dialogue

## Overview

A generic system for generating voiced NPC dialogue — the player activates an NPC and gets a
dialogue menu with voiced responses. Reusable across any generated content (dungeons, worldspaces,
city encounters).

**Per-NPC quests** — each generated NPC gets its own dedicated dialogue quest.

Distinct from the **audio data-slate** system (`SpeechTools.AddVoice`) which plays a one-sided
radio log with no player interaction. This system uses `DialogBranch` records (DLBR) and quest
stages, which are absent from audio-log quests.

---

## Dialogue Pattern — Staged Conversation

Mirrors the standard Starfield NPC interaction style:

```
Stage 0 (intro)
  NPC: "You shouldn't be here. Move along."
  ├─ [PROGRESS]  "What's going on at this facility?"   → advances to Stage 10
  ├─ [EXPLORE]   "Who are you?"                        → NPC replies, stays at Stage 0
  └─ [EXPLORE]   "Is it safe here?"                    → NPC replies, stays at Stage 0

Stage 10 (topic: reactor incident)
  NPC: "Reactor went offline three days ago. Running on backup power."
  ├─ [PROGRESS]  "What happened to the workers?"       → advances to Stage 20
  ├─ [EXPLORE]   "How bad is the damage?"              → NPC replies, stays at Stage 10
  └─ [EXPLORE]   "Did you report this?"                → NPC replies, stays at Stage 10

Stage 20 (last topic — no progress choice)
  NPC: "The workers didn't leave. They were taken. All twelve of them."
  ├─ [EXPLORE]   "Who took them?"                      → NPC replies, stays at Stage 20
  └─ [EXPLORE]   "Did anyone escape?"                  → NPC replies, stays at Stage 20

[Goodbye]  "Watch yourself out there."                 (always available)
```

**Rule:** the first choice always advances the conversation. The other choices expand on the
current stage — deeper context, lore, atmosphere — without moving forward.
**Last stage** has no progress choice; only explores + goodbye.

`StageCount` = `topics.Count + 1` (intro stage + one stage per topic).

## Data Model — `DialogueScript`

Generated by AI, consumed by `NPCDialogueNoun`. Decoupled from Mutagen.

```csharp
// Retrograde.Library/Models/DialogueScript.cs
namespace Retrograde.Models;

public class DialogueScript
{
    /// <summary>Number of stages = topics.Count + 1 (intro + one per topic).</summary>
    public int StageCount => Stages.Count;

    public List<DialogueStage> Stages { get; set; } = new();

    /// <summary>Always-available farewell line at the bottom of the menu.</summary>
    public string Goodbye { get; set; } = "";
}

public class DialogueStage
{
    /// <summary>NPC's spoken line when greeting fires at this stage.</summary>
    public string NpcLine { get; set; } = "";

    /// <summary>
    /// Player text for the "advance" choice. Null on the last stage
    /// (no more stages to progress to).
    /// </summary>
    public string? ProgressPrompt { get; set; }

    /// <summary>Side questions — expand on this stage without advancing it.</summary>
    public List<DialogueExchange> Explores { get; set; } = new();
}

public class DialogueExchange
{
    /// <summary>Player's menu text (≤60 chars recommended).</summary>
    public string PlayerPrompt { get; set; } = "";

    /// <summary>NPC's spoken reply (≤200 chars; AI prompt enforces this).</summary>
    public string NpcReply { get; set; } = "";
}
```

## AI Generation — `PromptManager.GetDialogueScript`

Single LLM call. Draws on the running LoreContext (same session as quest/NPC generation).
Caller passes:
- `npcDescription` — who this NPC is and their emotional state
- `topics` — ordered list of subjects the conversation should move through
- `addons` — freeform context strings (location, mission goal, etc.)

### Prompt Design

```
Generate a staged NPC conversation for a Starfield-style bounty hunting game.

NPC: {npcDescription}
Conversation topics (in order): {topic0}, {topic1}, {topic2}, ...

Use the LoreContext established earlier in this conversation for tone, setting, and names.
Do NOT invent new names or factions beyond the LoreContext.

Rules:
- There is one intro stage followed by one stage per topic listed above.
- Each stage has:
    NpcLine: what the NPC says at this stage (1-2 sentences, under 200 chars).
    ProgressPrompt: the player choice that moves to the next stage (under 60 chars).
      OMIT ProgressPrompt on the last stage — it has no continuation.
    Explores: exactly 2 player questions and NPC replies that expand on this stage.
      PlayerPrompt: under 60 chars. NpcReply: under 200 chars.
- Goodbye: 1 sentence. Always available. Under 100 chars.
- Tone: guarded, weary, and grounded. No drama. No metaphor.
- No stage directions, emotion labels, or quotes around dialogue.
- Output in this exact format:

< Dialogue >
    < Stage >
        < NpcLine >TEXT</ NpcLine >
        < ProgressPrompt >TEXT</ ProgressPrompt >
        < Explore >< PlayerPrompt >TEXT</ PlayerPrompt >< NpcReply >TEXT</ NpcReply ></ Explore >
        < Explore >< PlayerPrompt >TEXT</ PlayerPrompt >< NpcReply >TEXT</ NpcReply ></ Explore >
    </ Stage >
    ...one < Stage > block per stage, last stage omits < ProgressPrompt >...
    < Goodbye >TEXT</ Goodbye >
</ Dialogue >
```

### C# Implementation (in `PromptManager`)

```csharp
public static DialogueScript GetDialogueScript(
    string       npcDescription,
    List<string> topics,
    List<string> addons)
{
    var sb = new StringBuilder();
    sb.AppendLine("Generate a staged NPC conversation for a Starfield-style bounty hunting game.");
    sb.AppendLine();
    sb.AppendLine("NPC: " + npcDescription);
    sb.AppendLine("Conversation topics (in order): " + string.Join(", ", topics));
    sb.AppendLine();
    sb.AppendLine("Use the LoreContext established earlier in this conversation for tone, setting, and names.");
    sb.AppendLine("Do NOT invent new names or factions beyond the LoreContext.");
    sb.AppendLine();
    sb.AppendLine("Rules:");
    sb.AppendLine("- One intro stage, then one stage per topic listed.");
    sb.AppendLine("- Each stage: NpcLine (under 200 chars), ProgressPrompt (under 60 chars, omit on last stage),");
    sb.AppendLine("  exactly 2 Explores (PlayerPrompt under 60 chars, NpcReply under 200 chars).");
    sb.AppendLine("- Goodbye: 1 sentence, under 100 chars. Tone: guarded and grounded.");
    sb.AppendLine("- No stage directions or quotes.");
    sb.AppendLine();
    sb.AppendLine("Additional Information:");
    foreach (var a in addons) sb.AppendLine(a);
    sb.AppendLine();
    // Append format template so the model has a structural anchor
    int stageCount = topics.Count + 1;
    for (int i = 0; i < stageCount; i++)
    {
        sb.AppendLine("    < Stage >");
        sb.AppendLine("        < NpcLine >TEXT</ NpcLine >");
        if (i < stageCount - 1) sb.AppendLine("        < ProgressPrompt >TEXT</ ProgressPrompt >");
        sb.AppendLine("        < Explore >< PlayerPrompt >TEXT</ PlayerPrompt >< NpcReply >TEXT</ NpcReply ></ Explore >");
        sb.AppendLine("        < Explore >< PlayerPrompt >TEXT</ PlayerPrompt >< NpcReply >TEXT</ NpcReply ></ Explore >");
        sb.AppendLine("    </ Stage >");
    }
    sb.AppendLine("    < Goodbye >TEXT</ Goodbye >");

    string raw = AITools.RunPrompt(sb.ToString());
    for (int i = 0; i < 5 && !raw.Contains("<NpcLine>", StringComparison.OrdinalIgnoreCase); i++)
        raw = AITools.RunPrompt(sb.ToString());

    return ParseDialogueScript(raw);
}

private static DialogueScript ParseDialogueScript(string raw)
{
    var script = new DialogueScript { Goodbye = ExtractDialogTag(raw, "Goodbye") };

    foreach (var stageBlock in ExtractAllDialogTags(raw, "Stage"))
    {
        var stage = new DialogueStage
        {
            NpcLine        = ExtractDialogTag(stageBlock, "NpcLine"),
            ProgressPrompt = ExtractDialogTag(stageBlock, "ProgressPrompt")
                                 .NullIfEmpty(),   // null on last stage
        };
        foreach (var ex in ExtractAllDialogTags(stageBlock, "Explore"))
        {
            stage.Explores.Add(new DialogueExchange
            {
                PlayerPrompt = ExtractDialogTag(ex, "PlayerPrompt"),
                NpcReply     = ExtractDialogTag(ex, "NpcReply"),
            });
        }
        script.Stages.Add(stage);
    }

    return script;
}

// string.NullIfEmpty() extension: returns null if string is null or whitespace
```

## Record Chain

**Topics per stage** = 1 Greeting INFO per stage (all on the same Greeting Topic) + 1 Progress
Topic per non-final stage + 2 Explore Topics per stage + 1 Goodbye Topic.

```
Quest  (per-NPC, StartGameEnabled | StartsEnabled | HasDialogueData, Type=None)
  │
  ├─ QuestStages: [0, 10, 20, ...] — one per stage, no log text needed
  │
  ├─ Alias[0]: QuestReferenceAlias  (ID=0, UniqueActor → NPC base form)
  │
  ├─ DialogBranch  (inline, TopLevel | Player)
  │    └─ StartingTopic → "Greeting" topic
  │
  ├─ DialogTopic "Greeting"   (one topic, multiple stage-gated INFOs)
  │    ├─ Subtype = Greeting,  Branch → DialogBranch
  │    ├─ INFO[0]  condition: GetStage(quest)==0
  │    │    ResponseText = stages[0].NpcLine,  WEMFile, TextHash
  │    ├─ INFO[1]  condition: GetStage(quest)==10
  │    │    ResponseText = stages[1].NpcLine,  WEMFile, TextHash
  │    └─ INFO[N]  condition: GetStage(quest)==N*10
  │
  ├─ DialogTopic "Progress_0"   [one per non-final stage]
  │    ├─ Name = stages[0].ProgressPrompt      ← shown in player menu
  │    ├─ Subtype = Custom
  │    └─ INFO  condition: GetStage(quest)==0
  │         SetParentQuestStage.OnBegin = 10   ← advances to next stage
  │         ResponseText = ""  (no NPC reply — greeting fires immediately after)
  │
  ├─ DialogTopic "Explore_0_0"  [2 per stage]
  │    ├─ Name = stages[0].Explores[0].PlayerPrompt
  │    ├─ Subtype = Custom
  │    └─ INFO  condition: GetStage(quest)==0
  │         ResponseText = stages[0].Explores[0].NpcReply,  WEMFile
  │
  └─ DialogTopic "Goodbye"
       ├─ Subtype = Goodbye
       └─ INFO  (no stage condition — always available)
            ResponseText = script.Goodbye,  WEMFile
```

**Stage gating** — every INFO (except Goodbye) carries:
```
Condition: GetStage(questFormKey) == stageIndex * 10   [EqualTo, ConditionFloat]
```

**Stage advance** — Progress INFOs carry:
```
SetParentQuestStage.OnBegin = (short)((stageIndex + 1) * 10)
SetParentQuestStage.OnEnd   = 0
```

**Progress response text** — left empty (`""`). After the progress choice plays, the quest stage
advances and the Greeting topic re-fires automatically with the NPC's new opening line for the
next stage (Bethesda's standard "stage re-greet" behaviour). ⚠ Needs in-game verification.

## Quest Flags for Dialogue Quests

| Flag | Value | Notes |
|------|-------|-------|
| `StartGameEnabled` | `0x0001` | Quest active at game start |
| `StartsEnabled` | `0x0010` | Dialogue fires immediately |
| **`HasDialogueData`** | **`0x8000`** | **Required for DialogBranch quests** |
| `RunOnce` | — | **Do NOT set** — dialogue must be repeatable |
| `AddIdleTopicToHello` | `0x0004` | Optional — NPC says greeting unprompted as player passes |

```csharp
var data = new QuestData
{
    Flags = Quest.Flag.StartGameEnabled | Quest.Flag.StartsEnabled | Quest.Flag.HasDialogueData,
    Type  = Quest.TypeEnum.None,
};
```

## Mutagen Construction — `NPCDialogueNoun`

```csharp
// Retrograde.Library/Nouns/NPCDialogueNoun.cs

public class NPCDialogueNoun
{
    public Quest QuestRecord { get; }

    public NPCDialogueNoun(
        FormKey        npcFormKey,
        string         voiceTypeEditorId,
        DialogueScript script,
        string         suffix,
        string         elevenLabsVoiceId = "")
    {
        var targetMod = RetrogradeContext.Current.TargetMod;

        // ── Quest ──────────────────────────────────────────────────────────────
        var data = new QuestData
        {
            Flags = Quest.Flag.StartGameEnabled | Quest.Flag.StartsEnabled | Quest.Flag.HasDialogueData,
            Type  = Quest.TypeEnum.None,
        };
        var quest = new Quest(targetMod) { EditorID = "dlg_quest_" + suffix, Data = data };

        // Quest stages (one per dialogue stage, 10-increment)
        for (int i = 0; i < script.StageCount; i++)
            quest.Stages.Add(new QuestStage { Index = (ushort)(i * 10) });

        targetMod.Quests.Add(quest);

        // ── Alias ──────────────────────────────────────────────────────────────
        var alias = new QuestReferenceAlias { ID = 0, Name = "DialogNPC" };
        alias.UniqueActor.SetTo(npcFormKey);
        quest.Aliases.Add(alias);

        // ── DialogBranch ───────────────────────────────────────────────────────
        var branch = new DialogBranch(targetMod)
        {
            EditorID = "dlg_branch_" + suffix,
            Category = DialogBranch.CategoryType.Player,
            Flags    = DialogBranch.Flag.TopLevel,
        };
        branch.Quest.SetTo(quest.FormKey);
        quest.DialogBranches.Add(branch);

        // ── Greeting topic (shared — one INFO per stage) ───────────────────────
        var greetTopic = new DialogTopic(targetMod)
        {
            EditorID    = "dlg_greeting_" + suffix,
            Category    = DialogTopic.CategoryEnum.Player,
            Subtype     = DialogTopic.SubtypeEnum.Greeting,
            SubtypeName = DialogTopic.SubtypeNameEnum.Greeting,
        };
        greetTopic.Quest.SetTo(quest.FormKey);
        greetTopic.Branch.SetTo(branch.FormKey);
        quest.DialogTopics.Add(greetTopic);
        branch.StartingTopic.SetTo(greetTopic.FormKey);

        var greetInfoLinks = new ExtendedList<IFormLinkGetter<IDialogResponsesGetter>>();

        for (int i = 0; i < script.StageCount; i++)
        {
            var stage      = script.Stages[i];
            int stageValue = i * 10;

            // Greeting INFO for this stage
            var greetInfo = BuildInfo(targetMod, $"dlgi_greet_{suffix}_{i}",
                npcFormKey, voiceTypeEditorId,
                npcText: stage.NpcLine, playerPrompt: null,
                stageCondition: BuildStageCondition(quest, stageValue),
                stageAdvance: null,
                elevenLabsVoiceId, greetTopic.FormKey.ID);
            greetTopic.Responses.Add(greetInfo);
            greetInfoLinks.Add(greetInfo.FormKey.ToLink<IDialogResponsesGetter>());

            // Progress topic (non-final stages only)
            if (stage.ProgressPrompt != null)
            {
                var progTopic = BuildCustomTopic(targetMod, quest,
                    $"dlg_progress_{suffix}_{i}", stage.ProgressPrompt);
                var progInfo = BuildInfo(targetMod, $"dlgi_progress_{suffix}_{i}",
                    npcFormKey, voiceTypeEditorId,
                    npcText: "",  // no NPC reply — greeting re-fires after stage advance
                    playerPrompt: stage.ProgressPrompt,
                    stageCondition: BuildStageCondition(quest, stageValue),
                    stageAdvance: new DialogSetParentQuestStage
                    {
                        OnBegin = (short)(stageValue + 10),
                        OnEnd   = 0,
                    },
                    elevenLabsVoiceId: "", greetTopic.FormKey.ID);  // no audio on progress
                progTopic.Responses.Add(progInfo);
                progTopic.TopicInfoList = new ExtendedList<IFormLinkGetter<IDialogResponsesGetter>>
                    { progInfo.FormKey.ToLink<IDialogResponsesGetter>() };
                quest.DialogTopics.Add(progTopic);
            }

            // Explore topics
            for (int j = 0; j < stage.Explores.Count; j++)
            {
                var ex         = stage.Explores[j];
                var exTopic    = BuildCustomTopic(targetMod, quest,
                    $"dlg_explore_{suffix}_{i}_{j}", ex.PlayerPrompt);
                var exInfo = BuildInfo(targetMod, $"dlgi_explore_{suffix}_{i}_{j}",
                    npcFormKey, voiceTypeEditorId,
                    npcText: ex.NpcReply, playerPrompt: ex.PlayerPrompt,
                    stageCondition: BuildStageCondition(quest, stageValue),
                    stageAdvance: null,
                    elevenLabsVoiceId, exTopic.FormKey.ID);
                exTopic.Responses.Add(exInfo);
                exTopic.TopicInfoList = new ExtendedList<IFormLinkGetter<IDialogResponsesGetter>>
                    { exInfo.FormKey.ToLink<IDialogResponsesGetter>() };
                quest.DialogTopics.Add(exTopic);
            }
        }

        greetTopic.TopicInfoList = greetInfoLinks;

        // ── Goodbye (always available — no stage condition) ────────────────────
        var goodbyeTopic = new DialogTopic(targetMod)
        {
            EditorID    = "dlg_goodbye_" + suffix,
            Category    = DialogTopic.CategoryEnum.Player,
            Subtype     = DialogTopic.SubtypeEnum.Goodbye,
            SubtypeName = DialogTopic.SubtypeNameEnum.Goodbye,
        };
        goodbyeTopic.Quest.SetTo(quest.FormKey);
        quest.DialogTopics.Add(goodbyeTopic);

        var goodbyeInfo = BuildInfo(targetMod, "dlgi_goodbye_" + suffix,
            npcFormKey, voiceTypeEditorId,
            npcText: script.Goodbye, playerPrompt: null,
            stageCondition: null, stageAdvance: null,
            elevenLabsVoiceId, goodbyeTopic.FormKey.ID);
        goodbyeTopic.Responses.Add(goodbyeInfo);
        goodbyeTopic.TopicInfoList = new ExtendedList<IFormLinkGetter<IDialogResponsesGetter>>
            { goodbyeInfo.FormKey.ToLink<IDialogResponsesGetter>() };

        QuestRecord = quest;
    }

    // ── Private helpers ────────────────────────────────────────────────────────

    private static DialogTopic BuildCustomTopic(
        StarfieldMod targetMod, Quest quest, string editorId, string playerText)
    {
        var topic = new DialogTopic(targetMod)
        {
            EditorID    = editorId,
            Name        = playerText,
            Category    = DialogTopic.CategoryEnum.Player,
            Subtype     = DialogTopic.SubtypeEnum.Custom,
            SubtypeName = DialogTopic.SubtypeNameEnum.Custom,
        };
        topic.Quest.SetTo(quest.FormKey);
        // No Branch link on Custom/Goodbye topics — branch only used on Greeting
        return topic;
    }

    private static DialogResponses BuildInfo(
        StarfieldMod               targetMod,
        string                     editorId,
        FormKey                    npcFormKey,
        string                     voiceTypeEditorId,
        string                     npcText,
        string?                    playerPrompt,
        ConditionFloat?            stageCondition,
        DialogSetParentQuestStage? stageAdvance,
        string                     elevenLabsVoiceId,
        uint                       wemTopicId)
    {
        var info = new DialogResponses(targetMod)
        {
            EditorID         = editorId,
            SubtitlePriority = DialogResponses.SubtitlePriorityLevel.Low,
        };
        if (playerPrompt != null) info.Prompt = playerPrompt;
        if (stageCondition != null) info.Conditions.Add(stageCondition);
        if (stageAdvance   != null) info.SetParentQuestStage = stageAdvance;
        info.Speaker.SetTo(npcFormKey);

        if (!string.IsNullOrEmpty(npcText))
        {
            var textHash = SHA256.HashData(Encoding.UTF8.GetBytes(npcText))[..4];
            info.Responses.Add(new DialogResponse
            {
                ResponseText = npcText,
                WEMFile      = wemTopicId,      // {topicId:X8}.wem ⚠ unverified for live dialogue
                TextHash     = textHash,
                EmotionOut   = 7.466667f,
            });
            SpeechTools.GenerateWavs(wemTopicId, voiceTypeEditorId,
                targetMod.ModKey, npcText, elevenLabsVoiceId);
        }

        return info;
    }

    private static ConditionFloat BuildStageCondition(Quest quest, int stageValue)
    {
        var condData = new GetStageConditionData();
        condData.FirstParameter = new FormLinkOrIndex<IQuestGetter>(
            quest.FormKey.ToLink<IQuestGetter>());

        return new ConditionFloat
        {
            ComparisonValue = (float)stageValue,
            CompareOperator = CompareOperator.EqualTo,
            Data            = condData,
        };
    }
}
```

## Dialogue Quest vs AudioLog Quest

| | AudioLog Quest | Dialogue Quest |
|---|---|---|
| Flags | `StartGameEnabled \| StartsEnabled \| RunOnce \| 0x100000` | `StartGameEnabled \| StartsEnabled \| HasDialogueData` |
| `DialogBranch` | none | **required, inline** |
| `DialogTopic.Subtype` | `CustomScene` | `Greeting` / `Custom` / `Goodbye` |
| `DialogTopic.Branch` | always null | Greeting only |
| Quest stages | none | one per dialogue stage (0, 10, 20…) |
| Stage conditions on INFOs | none | `GetStage(quest) == N` on all except Goodbye |
| `SetParentQuestStage` on INFO | none | on Progress INFOs only |
| Scene / RadioSceneAction | required | **not used** |
| `DialogResponses.Prompt` | absent | set on all non-Greeting INFOs |

## Open Questions

1. **WEMFile for live NPC dialogue** — `{topicId:X8}.wem` confirmed for RadioSceneAction audio slates.
   Whether it works for player-activated dialogue needs an in-game test. If not, need to
   reverse-engineer Starfield's NPC voice file resolution.

2. **Progress response text** — Progress INFOs currently have empty `ResponseText` and no audio.
   The assumption is the Greeting topic re-fires after the stage advances (Bethesda's standard
   behaviour). If the engine doesn't auto-re-greet, the progress INFO needs its own NPC reply line.

3. **Custom topic visibility** — How the engine decides which Custom topics appear in the player
   menu after the Greeting (progress + explores for the current stage) needs vanilla verification.
   Current assumption: stage condition on the INFOs is sufficient. May also need the Custom topics
   to have a `Branch` link.

4. **`HasDialogueData` flag** — present in `Quest.Flag` enum, logically required, but not verified
   against a live Starfield dialogue quest dump.

5. **Greeting re-fire ordering** — When multiple Greeting INFOs are on the same topic, the engine
   picks the first one whose conditions pass. Conditions must be tight (EqualTo, not GreaterEqual)
   so only one stage's greeting plays at a time.
